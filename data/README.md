# Data

The dataset is **confidential and is not published** in this repository. This folder only documents its structure, so that the pipeline can be understood and reproduced with your own data.

## Expected layout

```
data/
├── raw/                    # one JSON file per domain and language (9 files)
│   ├── Hospitality/
│   ├── Logistics/
│   └── Support_Client/
└── processed/              # generated by the notebooks
    ├── dataset_clean.csv
    ├── dataset_clean_EDA.csv
    ├── train_data.csv
    └── test_data.csv
```

## Raw format

Each raw file is a list of annotated chatbot conversations:

```json
[
  {
    "id": "FR_EXAMPLE_0001",
    "language": "fr",
    "domain": "example",
    "final_sentiment": "positive",
    "conversation": [
      { "speaker": "bot",  "text": "Hello, how can I help you?" },
      { "speaker": "user", "text": "I would like to change my booking.", "sentiment": "neutral" },
      { "speaker": "user", "text": "Perfect, thank you!", "sentiment": "positive" }
    ]
  }
]
```

The example above is invented. Only `user` turns are kept for training.

## Dataset statistics

| | |
|---|---|
| Messages extracted | 4,271 |
| After removing exact duplicates | 4,199 |
| Train / test split | 3,359 / 840 (80 / 20) |
| Languages | Darija (Latin script) 1,683, French 1,443, English 1,073 |
| Domains | Customer support 1,746, Hospitality 1,283, Logistics 1,170 |
| Classes | Neutral 1,504, Positive 1,381, Negative 1,314 |
| Message length | 9.2 words on average, 31 at most |

Three rare labels (`surprised`, `anxious`, `worried`, 18 messages in total) are merged into `negative`.

## Using your own data

1. Put your JSON files in `data/raw/` following the format above (adapt the `FILES` mapping in `notebooks/01_preprocessing.ipynb` if your names differ).
2. Run `01_preprocessing`, then `02_EDA`, which writes `train_data.csv` and `test_data.csv`.
3. Fine-tune the models with notebooks `03` to `05` (see `models/README.md`).
